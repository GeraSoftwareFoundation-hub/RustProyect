# Rust 2D Game Project Documentation

## Introduction
This project is a 2D game developed using the Bevy game engine in Rust. Bevy is a data-driven game engine built in the Rust programming language that focuses on flexibility and speed.

## Getting Started
To get started with the project:
1. Clone the repository:
   ```bash
   git clone https://github.com/GeraSoftwareFoundation-hub/RustProyect.git
   ```
2. Navigate to the project directory:
   ```bash
   cd RustProyect
   ```
3. Install the necessary dependencies:
   ```bash
   cargo run
   ```

## Features
- 2D Rendering with Bevy
- Game State Management
- Asset Loading

## Project Structure
- `src/`: Contains the source code of the game.
- `assets/`: Contains game assets such as images and sounds.
- `Cargo.toml`: The project configuration file containing dependencies.
